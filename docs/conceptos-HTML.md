# 🌐 Conceptos Básicos de HTML Aplicados

En esta sección se documenta la estructura inicial del proyecto, desarrollada desde cero aplicando los fundamentos de HTML semántico y accesibilidad web.

## 🧱 Estructura Semántica Utilizada
Para el "Generador de Colores" se priorizó el uso de etiquetas nativas de HTML5 que dan significado al contenido y mejoran la accesibilidad (A11y):
- `<header>`: Encabezado principal que contiene el título de la aplicación y la descripción general.
- `<main>`: Contenedor principal donde se despliega la interfaz interactiva con las tarjetas de colores.
- `<section>` y `<div>`: Agrupaciones lógicas para organizar los controles, botones y la cuadrícula de colores.
- `<footer>`: Sección inferior destinada a los créditos del autor y enlaces al repositorio.

## ♿ Buenas Prácticas Aplicadas
- **Foco visible (`:focus-visible`):** Asegura que los usuarios que navegan mediante el teclado puedan identificar claramente en qué elemento interactivo se encuentran.
- **Atributos de accesibilidad:** Uso de atributos orientados a lectores de pantalla para mejorar la experiencia de usuario inclusiva.
